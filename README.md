# Rock Paper Scissors

A simple Rock Paper Scissors game built with JavaScript as part of **The Odin Project** Foundations course.

The game is played entirely in the browser console. The player competes against the computer in five rounds, and the final winner is determined by the total score.

## Features

- Random computer choice
- Player input using `prompt()`
- Five-round game
- Score tracking
- Round-by-round results displayed in the console
- Final game winner announcement

## Technologies Used

- HTML5
- JavaScript (ES6)

## How to Run

1. Clone this repository:
2. Open the project in VS Code
3. Start the project using Live Server
4. Open the browser console
5. Play by entering one of the following choices when prompted:
- rock
- paper
- scissors
